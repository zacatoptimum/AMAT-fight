# Contract Review Playbook v0.1

> 本playbook是commercial review與project coordination工具，不是法律意見。法律解釋、可執行性、法規適用、權利義務與正式redline須由 AMAT 指定qualified counsel負責；NDA、privilege與InfoSec要求 `TBD WITH CLIENT`。

## 1. Review objective

確認draft documents是否實現 G8 commercial mandate，並把每個差異轉成：business effect、priority、preferred / fallback position、evidence、owner、counsel question與negotiation action。

## 2. Commercial review vs legal advice

| Optimum commercial review | Qualified legal advice |
|---|---|
| 數量、價格、settlement與風險配置的business effect | 條文法律意義、可執行性、法定要求與法律風險 |
| 操作責任、timeline、data / certificate流程 | governing law、remedies、liability、regulatory interpretation |
| 對scenario / economics / implementation的影響 | 正式redline、legal opinion、privilege與signing authority |
| 提出clarification與commercial position | 核准法律文字與法律風險接受建議 |

遇到不確定就標 `COUNSEL REQUIRED`，不自行填補法律結論。

## 3. Document control

一個index記 agreement、schedules、term sheet、guarantee、wheeling / site documents、technical / data annex、certificate annex、addenda；每份有version / date / source / status / reviewer。Review只在指定base version進行；新版本需重新比對open issues。

## 4. Clause / issue checklist

- parties、authority、scope、definitions、order of precedence；
- volume / profile / delivery point / allocation / metering；
- COD、milestones、longstop、delay、conditions precedent；
- price、index、tax / fee / loss、invoice、payment、settlement / true-up；
- wheeling、network / site cooperation、data / audit；
- T-REC ownership、issuance、transfer、claim、replacement、no double claim；
- curtailment、shortfall、forecast / imbalance、replacement；
- representations、warranties、covenants；
- credit support、guarantee、collateral、rating / deterioration；
- change in law / tariff、force majeure；
- default、remedy、liability / cap、indemnity（counsel leads legal view）；
- termination、termination payment、step-in / assignment / change of control；
- confidentiality、data / cybersecurity、publicity；
- dispute、governing law、notices、signatures；
- transition / BAU、reporting、records、survival。

## 5. Risk-allocation test

對每項event問：誰控制、誰承擔、怎麼量、何時通知、如何補救、是否有cap / security、長期失敗能否退出、對成本 / claim / operations的downside。文字若無法回答，就建立issue，不用假設。

## 6. Prioritisation

`P0` 可能違反policy / authority或造成不可接受風險，先停並升級；`P1` 影響economics / deliverability / claim，談判前必須有position；`P2` 可透過clarification / drafting解決；`P3` housekeeping。Priority不等於法律嚴重性，兩者需分開。

## 7. Handoff to negotiation

每個3.3 agenda item引用同一 Issue ID、term ID、clause / version、target / fallback、speaker、authority、evidence與stop rule。會後用agreed / supplier to revert / client to decide / counsel required更新，不自行把口頭共識當final contract。
