# Supplier_Response_Template.xlsx — Model README

Sheets：`Instructions`、`Bidder Profile`、`Supply Offer`、`Pricing`、`Risk & Terms`、`Evidence Index`、`Compliance Summary`。IDs與units不可自行改；一列一個 offer block / price component / clause position / evidence item。`Compliance Summary` 檢查 mandatory fields與exceptions，但不自動決定 shortlist。Seeded offer為 demo，發標前清除並以 G6 assumptions鎖版。
