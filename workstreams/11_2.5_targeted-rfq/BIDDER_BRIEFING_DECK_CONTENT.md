# Bidder Briefing Deck — Content Source v0.1

1. **A disciplined process will create comparable proposals without implying award** — purpose, non-binding / issued-process status, confidentiality.
2. **Respond to the issued assumptions; expose every dependency and exception** — requirement boundary, common units / dates / profile.
3. **Separate contracting entity, route and underlying assets** — ownership / control and stable IDs.
4. **Price must reconcile from components to an all-in view** — currency, unit, index, fees, tax, losses, sensitivity.
5. **Delivery and certificate claims require evidence** — COD, volume, wheeling / meter, T-REC, no double claim.
6. **Questions follow one channel and material answers become addenda** — Q&A protocol and equal information.
7. **Evaluation starts with compliance, then value and DD** — hard screens, criteria, no lowest-price promise.
8. **Close with deadlines, submission checklist and contacts** — all actual dates / contacts TBD WITH CLIENT.

Each slide uses a conclusion title, 3–6 bullets / table concept, and speaker note identifying bidder question; target 8 slides.
