# Negotiation Strategy Memo v0.1

> `PRE-NEGOTIATION DRAFT`。Supplier、positions、authority、walk-away與economics均為 `TBD WITH CLIENT`；demo content不可在真實會議直接使用。

## Objective

第一輪目標不是關閉全部條款，而是：確認雙方decision drivers、在最高價值issues取得可驗證movement、建立package trade可能、暴露真正red lines，並保持替代方案。

## Issue brief format

每項Issue ID記：current text / position、business effect、client target、fallback、unacceptable、supplier interest hypothesis、opening question、evidence、authorized trade、pause / escalation trigger、speaker與note owner。

## Concession logic

不做單向讓步。每個give要有：what / why、requested get、estimated value / risk、authority、expiry / conditionality、interaction with other terms。先交換低成本高價值項，保留關鍵trade；若對方要求立即commit，使用「subject to client approval / document review」並記錄。

## Walk-away / escalation

遇到must-have被拒、超出price / risk boundary、要求exclusivity / competitor confidential info、法律 / policy issue未經counsel、或authority不清時pause。Walk-away不是談判者即場決定，除非已有明確client mandate。

## Meeting roles

Lead speaker控制agenda；commercial lead解釋value / trade；counsel處理legal questions / drafting；subject owner回答facts；independent note owner記issue / statement / commitment status；authority holder只在mandate內決定。會前指定single voice與private caucus signal。

## Post-meeting record

30分鐘內capture：agreed in principle / supplier to revert / client to decide / counsel required / not agreed；exact caveat；give / get；document change request；owner / date。24小時內與counterparty確認factual action list（是否對外由client決定），不把internal strategy寄出。

## Preliminary strategy

`HYPOTHESIS`：第一輪以COD / delivery、certificate、price / settlement與credit / remedy的package trade為核心，比逐條順序review更能發現整體交換空間。實際優先順序需G8 mandate與counsel review。

## Handoff

3.4用tracker比較remaining issue、revised economics、risk acceptance與best alternative；若供應商送新redline，3.2先更新issue mapping，再進下一輪。
