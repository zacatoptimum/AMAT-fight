# 3.3 第一輪談判與修正 — Work Package

## Purpose
依G8 mandate處理最高價值issues、測試counterparty priorities，並留下可追溯的give / get、open item與修正版需求。
## Client question
第一輪要取得哪些movement、可以交換什麼、何時pause / escalate？
## Intended decision
核准第一輪positions與會後：accept / counter / clarify / escalate / stop。
## Client audience
Negotiation team、client approvers、Legal、Finance、Sustainability、Facilities。
## Optimum owner / supporting role
Negotiation Lead owner；client lead holds authority；Legal handles legal text/advice；note owner independent；Project Lead debrief。
## Inputs
3.1 mandate、3.2 issue list / counsel guidance、supplier draft / offer、authority matrix。
## Activities
meeting brief → role rehearsal → negotiation → contemporaneous record → debrief → tracker / redline instructions → client decision。
## Outputs
`NEGOTIATION_STRATEGY_MEMO.md/.docx`、`Negotiation_Tracker.xlsx`、`MODEL_README.md`、meeting brief / post-meeting record formats。
## Dependencies
輸出餵3.4 remaining issues / impact、3.5 agreed terms / CP。
## Known
只有authorized client代表可承諾；口頭alignment不是final agreement；supplier confidential terms不可外洩。
## Hypotheses
少量package trades與clear pause points可提高quality並避免連鎖讓步。
## TBD with client
lead speaker、authority、meeting attendees、supplier sequencing、walk-away、concession values、legal / finance real-time availability。
## Key risks
無對價讓步、越權、記錄不一致、單條改善造成其他風險、版本漂移、time pressure、relationship damage。
## MVP sequence
top 5 issue brief → mock session → first meeting → 30-minute debrief → same-day tracker → client review before counter。
## Definition of Done
每個issue有opening / target / fallback、authority、give/get、supplier rationale、outcome、evidence、owner / date；無未授權承諾，post-meeting record與document revision一致。
