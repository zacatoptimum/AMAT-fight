# 1.3 台灣市場與再生能源採購工作坊 — Work Package

## Purpose

讓 AMAT 的跨部門參與者以共同語言理解台灣企業再生能源採購的 participant、energy / contract / certificate flow、option trade-offs 與 execution dependencies，並把學習轉成 1.4–1.6 所需的 client decisions / inputs。

## Client question

「台灣有哪些可行 procurement paths、每條路如何運作、AMAT 必須承擔什麼 trade-off，以及我們現在要提供或決定什麼？」

## Intended decision

確認分析 boundary / priority、需要深入的 procurement options、1.4–1.5 assumptions、data / stakeholder owners、decision criteria與 1.6 roadmap / 2.x engagement前置條件。

## Client audience

HYPOTHESIS：Taiwan sustainability / RE100 owner、Procurement、Facilities / site energy owners、Finance、Legal、regional / global sustainability、regional / global procurement、relevant decision makers。不是所有人都需全程；participant design 依 decision role調整。

## Optimum owner / supporting role

Owner：Project Lead / lead facilitator。Supporting：Taiwan market SME、procurement analyst、note / decision recorder、timekeeper、model owner。Client sponsor / co-facilitator TBD。

## Inputs

1.1 charter / audience / decisions、1.2 early data findings、client target / policy definition、participant prior knowledge、official current Taiwan market / T-REC sources、questions / assumptions log。

## Activities

1. Sponsor alignment：確認 workshop objective不是 generic training，而是決策準備。
2. Participant mapping與短 pre-read / pre-survey。
3. 以「why → how the market works → options → trade-offs → AMAT implications → decisions / inputs」facilitate。
4. 用 worked example（synthetic）測試 electricity / contract / certificate flows。
5. 捕捉 decisions、misalignments、data asks、research questions、owners / dates。

## Outputs

- `WORKSHOP_DESIGN_AND_FACILITATOR_GUIDE.md/.docx`
- `WORKSHOP_DECK_CONTENT.md`
- `Taiwan_Market_Workshop_Deck.pptx`
- workshop decision / action record（可用 shared register / minutes template）

## Dependencies

依賴 1.1 sponsor / participant availability、1.2 early gaps、approved confidentiality / research rules。輸出定義 1.4 gap口徑、1.5 scenario / criteria、1.6 stakeholders / gates，並降低2.x市場接觸誤解。

## Known

- 台灣制度存在直供、轉供、自發自用與憑證相關流程；current details 需以官方規章 / T-REC guidance驗證。
- T-REC制度把憑證申請、電量累計、讓與與使用 / 宣告分開管理；具體適用性需 client policy / counsel確認。
- AMAT-specific site、volume、target、budget、policy與 stakeholder facts 未知。

## Hypotheses

- AMAT audience的最大需求不是完整法規課程，而是選項 trade-off與 internal decision implications。
- Workshop前 knowledge levels不同，需要 role-based questions與 concise pre-read。
- Facilities / Procurement / Sustainability需共同理解 energy flow、commercial contract與certificate evidence不是同一件事。

## TBD with client

Audience、duration、prior knowledge、language、legal review、target / claim rules、decision priorities、sensitive topics、是否需要 supplier participation（v0.1建議不在 alignment workshop納入外部 supplier）。

## Key risks

- 只講市場知識，沒有帶回 client decisions。
- 把 current regulatory / operational detail過度簡化或講成法律意見。
- 參與者太多但角色不清，workshop變資訊廣播。
- 用未驗證 AMAT facts示例，造成錯誤期待。

## MVP sequence

1. MVP-0：15-slide deck content + facilitator run-of-show + synthetic flow example。
2. MVP-1：與 sponsor 30分鐘 review目標、audience、decisions、sensitive topics。
3. Pilot：Optimum internal dry run，測 timing / questions / outputs。
4. Deliver：facilitate + live decision / action capture。
5. Correct / Expand：48小時內回傳 decision record、input requests、1.4–1.6 implications。

## Definition of Done

- 每個 slide有 message title、key message / content、visual、discussion prompt。
- Deck涵蓋 why、participants、flows、onsite / offsite / PPA / retailer / T-REC / wheeling、trade-offs、constraints、AMAT implications、decisions與data asks。
- 市場機制 claims 有 source / date；未驗證細節標 RESEARCH REQUIRED。
- Participant hypothesis明示，不冒充AMAT org chart。
- Outputs已餵入1.4、1.5、1.6並指派 owner / due；DOCX / PPTX通過 validation與逐頁 render QA。
