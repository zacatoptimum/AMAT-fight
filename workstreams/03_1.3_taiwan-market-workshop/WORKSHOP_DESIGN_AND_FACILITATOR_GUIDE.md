# Taiwan Renewable Electricity Procurement Workshop — Design and Facilitator Guide v0.1

> PRE-KICKOFF DRAFT。AMAT stakeholder design、target、site、volume、policy與 preferences均為 TBD WITH CLIENT。本文件提供 market education / decision facilitation，不是法律意見。

## 1. Workshop objective

工作坊結束時，參與者應能：

- 用共同語言描述台灣企業綠電 procurement path中的 buyer、generator / developer、renewable electricity retailer、grid / wheeling與 T-REC interfaces。
- 區分 physical electricity、commercial contract / settlement、certificate / claim evidence三種 flow。
- 理解 onsite、direct supply、wheeling / retailer-enabled PPA、certificate-only等 options的 volume、tenor、price、flexibility、execution complexity與risk差異。
- 對 AMAT 應優先分析的 options、decision criteria、inputs、owners與 next gates形成初步共識。

Workshop不以完成所有法規 / 合約教學為目的，也不在沒有AMAT資料時預先選定供應商或結論。

## 3. Recommended format

### 120-minute decision workshop

| Time | Module | Purpose | Output |
|---|---|---|---|
| 0–10 | Why this matters / objectives | 建立共同decision context | confirmed objectives / parking lot |
| 10–35 | Market participants and three flows | 共同語言 | clarified terms / misunderstandings |
| 35–60 | Procurement paths | 理解可行結構與 interfaces | options to assess / exclude from MVP |
| 60–70 | Break / pulse check | 收斂 open questions | prioritised questions |
| 70–95 | Trade-offs and constraints | 設定1.5 criteria | draft decision criteria / weights |
| 95–112 | AMAT implications and data needs | 連到1.4–1.6 | owners / inputs / due dates |
| 112–120 | Decisions and close | 確認 next gates | decisions / actions / open issues |

若只允許90分鐘，縮短option deep dive，不刪除決策與data owner段落。

## 4. Market structure teaching frame

### Participants

- Corporate buyer：定義需求、contracting / credit、internal approvals、claim / reporting、implementation owner。
- Renewable generator / developer：project / asset、generation、COD / availability、delivery / curtailment / performance evidence。
- Renewable electricity retailer：可聚合 / 購售、contract interface、settlement / service與市場接觸角色；實際責任依proposal / contract驗證。
- Taipower / grid interface：在轉供 / 併網型直供情境涉及network / operational process與電量資料；current process以官方規章為準。
- T-REC Center / BSMI：憑證申請、查驗、電量累計、讓與、使用 / 宣告的制度介面。
- Advisors / legal counsel / verifiers：方法、商務、法律、查驗角色須分清。

### Three flows

1. Electricity / operational flow：generation → grid / direct connection → buyer meter / account；涉及site、meter、timing與actual delivery。
2. Contract / money flow：PPA / retailer / service / network / settlement agreements；涉及price、volume、tenor、credit、default、change、tax / accounting。
3. Certificate / claim flow：generation verification → certificate issuance → transfer / ownership → use / claim record；不得只因簽了electricity contract就假設claim evidence完整。

Facilitator應要求參與者對每個option分別指出三種flow與owner。

## 5. Procurement option frame

| Option archetype | Strategic use | Strengths to test | Constraints / risks to test | Client questions |
|---|---|---|---|---|
| Onsite self-generation / self-use | site-level visible action、部分load coverage | site proximity、potential operational / reputational benefit | roof / land、capex / opex、generation profile、site tenure、certificate treatment | 哪些sites / loads / ownership可行？ |
| Direct supply | generator-to-user direct line in qualifying structure | potentially clearer physical linkage | location / interconnection / capex / operational feasibility | 是否有site-specific condition值得研究？ |
| Offsite wheeling PPA | medium / long-term core volume | scale、tenor、technology / project linkage | project maturity、COD、profile、wheeling、curtailment / delivery、credit、contract complexity | 需要多少firmness / flexibility？ |
| Retailer-enabled procurement | access / aggregation / interface simplification | portfolio / operational support potential | pass-through terms、supplier dependence、transparency、credit / settlement | AMAT要single interface還是asset-level control？ |
| Certificate-only / unbundled T-REC | gap-filling / timing flexibility subject to policy | speed、smaller volume、limited physical integration | eligibility / additionality / vintage / availability / claim treatment / price | global policy如何看待？用於何種gap？ |
| Portfolio combination | balance timing、risk、volume、technology | diversification / staged execution | governance、double count、data / reconciliation complexity | 哪些constraints must be satisfied together？ |

表格是 analysis framework，不是 AMAT recommendation。

## 6. Trade-off axes

使用1–5 scale前先定義量尺；不在 workshop中無依據打分。至少討論：

- Volume / coverage / profile fit
- Timing / COD / contract start
- Tenor / renewal / exit / flexibility
- Price structure / escalation / settlement / budget volatility
- Technology / asset / project maturity / concentration
- Delivery / curtailment / generation / counterparty risk
- Wheeling / meter / certificate / implementation complexity
- Claim / RE100 relevance under client policy
- Legal / credit / guarantee / change / termination complexity
- Internal resource and approval burden

## 7. Taiwan market constraints discussion

避免以一句「市場缺電 / 缺綠電」取代 evidence。將限制拆成：

- Asset / supply availability and project maturity
- Network / wheeling / meter / operational process
- Certificate issuance / transfer / claim timing
- Contracting / credit / guarantee and counterparty capacity
- Volume / profile / technology / site fit
- Internal approval / data / timeline constraints

對每一項區分 official rule、supplier statement、public evidence、Optimum analysis、client decision。

## 8. Discussion questions by module

### Why / success

- 此project最重要是target compliance、execution certainty、cost visibility、portfolio resilience或其他？
- 哪個decision / deadline不能錯過？

### Flows / roles

- 哪個function擁有electricity data、contract、certificate / claim、budget與site implementation？
- 哪個interface最容易被誤以為「別人會處理」？

### Options / trade-offs

- 哪些option必須納入1.5 base case / sensitivity？
- 哪些constraints是hard constraint，哪些只是preference？
- 更重視scale / long-term economics，還是speed / flexibility？

### Decisions / inputs

- 1.4 residual gap口徑誰批准？
- 1.5 criteria / weights與risk tolerance誰批准？
- 進2.x前，identity / volume / site / timing可揭露到什麼程度？

## 9. Facilitator run-of-show

### Before

- Sponsor alignment：objective、decisions、participants、sensitive topics、what not to decide。
- Send 2-page pre-read / 5-question survey；不要先發完整法規資料包。
- Assign facilitator、market SME、note / decision recorder、timekeeper。
- 準備decision log、parking lot、action log與truth-status legend。

### During

- 開場先確認「今日要決定 / 不決定」。
- 每個fact標 source / date；遇到未確認current detail標 RESEARCH REQUIRED，不即席猜。
- 每個option先畫三種flow，再談price / recommendation。
- 出現 disagreement時記錄 decision owner、needed evidence、latest-needed date。
- 10分鐘一次 pulse check；timebox deep dive，移入 parking lot。

### After — within 48 hours

- 發送 workshop decision / action / assumption / question record。
- 將 data asks寫回 1.2 tracker。
- 將 gap boundary寫入1.4 model assumptions。
- 將 option / criteria / constraints寫入1.5 scenario design。
- 將 stakeholders / approvals / deadlines寫入1.6 roadmap。
- 需研究的 current market / legal detail進 source / research log。

## 11. Source and research protocol

### Official reference set — accessed 2026-09-27

- [T-REC documents and current application guidance](https://www.trec.org.tw/documents) — official operational guides, including self-use and direct / wheeling facility certificate guidance.
- [Implementation Regulations Governing Renewable Energy Certificates](https://www.trec.org.tw/index.php/en/regulations) — official descriptions of certificate application, issuance / accrual, transfer and claim use.
- [Taipower wheeling and grid-connected direct supply operating rules](https://service.taipower.com.tw/powerwheeling/static/file/1130318%E8%BD%89%E7%9B%B4%E4%BE%9B%E7%87%9F%E9%81%8B%E8%A6%8F%E7%AB%A0.pdf) — official operating reference; check latest revision before client delivery.
- [Electricity Act copy published by Taipower](https://service.taipower.com.tw/powerwheeling/static/file/1130718%E9%9B%BB%E6%A5%AD%E6%B3%95.pdf) — legal definitions / authorities; formal legal interpretation remains client counsel's role.

### Use rule

- Every current-process claim in client material gets source / publication or access date.
- Check latest version immediately before workshop; webpage or PDF may change.
- Do not present supplier statements as official rules or legal advice.
- Public market data、price、availability、project claims not yet researched remain RESEARCH REQUIRED。
