# Taiwan Market Workshop Deck — Content Source

## Storyline

15 slides，約120分鐘。先回答why，再建立participants與三種flow，接著比較procurement paths與trade-offs，最後把市場知識轉成AMAT decisions、data asks與1.4–1.6 handoff。AMAT-specific內容均保留TBD。

## Slide 1 — Understanding the interfaces is the prerequisite to choosing a Taiwan procurement strategy

- Key message：策略不是先選產品名，而是先理解electricity、contract與certificate interfaces及internal decision needs。
- Content：title / workshop purpose / PRE-KICKOFF truth-status note。
- Visual：three connected flows leading to decisions。
- Discussion：今天最重要的decision / learning是什麼？

## Slide 2 — Today’s goal is decision readiness, not a complete regulatory course

- Key message：workshop成功標準是共同語言、options to assess、criteria、owners與next gates。
- Content：will / will not do；outputs。
- Visual：two columns + final outputs strip。
- Discussion：有哪些topic需要另開legal / technical deep dive？

## Slide 3 — The right participants change by the decision being prepared

- Key message：Sustainability、Procurement、Facilities、Finance、Legal與regional / global functions都可能需要參與，但角色不同。
- Content：participant hypothesis and segment relevance。
- Visual：role-to-decision map；全部標HYPOTHESIS。
- Discussion：誰missing、誰optional、誰是decision owner？

## Slide 4 — Taiwan procurement involves five interfaces that AMAT must coordinate

- Key message：buyer、generator / developer、retailer、grid / Taipower、T-REC / verification需要清楚owner與handshake。
- Content：participant roles；advisor / counsel as support。
- Visual：buyer-centered ecosystem map。
- Discussion：目前AMAT內部誰擁有每個interface？

## Slide 5 — Electricity, contracts and certificates move through different but linked systems

- Key message：physical supply、commercial settlement與claim evidence不可混為同一件事。
- Content：three flows、example handoffs、owner fields。
- Visual：three horizontal lanes。
- Discussion：哪個flow目前最不清楚？

## Slide 6 — Onsite generation trades scale for site control and visible implementation

- Key message：onsite可成為portfolio一部分，但須測site / roof / tenure、generation profile、commercial ownership與certificate treatment。
- Content：decision tests，不提供AMAT feasibility conclusion。
- Visual：site flow + strength / constraint cards。
- Discussion：哪些site條件值得先收資料？

## Slide 7 — Offsite procurement requires coordinated delivery interfaces

- Key message：offsite PPA / retailer-enabled structures需同時看asset、COD、volume / profile、wheeling、settlement、certificate與credit。
- Content：dependency chain and diligence questions。
- Visual：project → network → buyer plus contract / certificate overlays。
- Discussion：哪些dependency會成為AMAT hard constraint？

## Slide 8 — Certificate-only procurement can fill timing gaps but must be tested against policy and evidence rules

- Key message：T-REC可提供flexibility，但eligibility、vintage、ownership / transfer、claim registration與availability需分別確認。
- Content：use case / risks / verification steps；official-source note。
- Visual：certificate lifecycle。
- Discussion：global / regional policy接受條件為何？

## Slide 9 — A portfolio combines tools because no single option optimizes every objective

- Key message：short-term flexibility與long-term core volume應在共同constraints下組合。
- Content：illustrative archetypes：near-term gap filler、medium-term bridge、long-term core；SYNTHETIC, not recommendation。
- Visual：three-horizon stack。
- Discussion：哪個horizon最受deadline影響？

## Slide 10 — Option comparison must make trade-offs explicit before any scoring

- Key message：volume、timing、tenor、price、technology、flexibility、delivery / market risk、concentration、implementation與claim fit需定義量尺。
- Content：trade-off matrix headings；no AMAT scores。
- Visual：criteria wheel / matrix。
- Discussion：哪些是hard constraints、哪些是preferences？

## Slide 11 — Taiwan constraints need evidence-based decomposition

- Key message：避免以market slogan取代analysis；將availability、project maturity、network / wheeling、certificate timing、credit / contract與internal readiness分開。
- Content：constraint → evidence → owner → decision effect。
- Visual：six-row mapping。
- Discussion：哪些限制需要official research、supplier evidence或client input？

## Slide 12 — AMAT’s strategy will depend as much on internal readiness as on external supply

- Key message：data、approval、budget、legal mandate、site implementation與claim governance可能是critical path。
- Content：internal readiness checklist，全部TBD WITH CLIENT。
- Visual：two-sided external vs internal critical path。
- Discussion：哪個internal lead time最長？

## Slide 13 — The next analysis needs a clear residual-gap boundary and an approved criteria set

- Key message：1.4需要boundary / target / existing coverage；1.5需要constraints / criteria / scenarios。
- Content：input-to-output handoff。
- Visual：1.2 inputs → 1.4 gap → 1.5 portfolio → 1.6 roadmap。
- Discussion：誰批准boundary、assumptions、criteria與scenario？

## Slide 14 — Market engagement should start only after AMAT approves what can be disclosed

- Key message：anonymous sounding、named outreach、RFQ與negotiation有不同information boundary與commitment risk。
- Content：disclosure ladder、no false commitment、neutrality。
- Visual：four-stage ladder。
- Discussion：identity、volume、site、timing在哪個stage可揭露？

## Slide 15 — Close with decisions, owners and dates that unlock 1.4–1.6

- Key message：workshop不是以Q&A結束，而以decision / action / data / research record結束。
- Content：success priority、gap boundary、options、hard constraints、criteria、disclosure、owners、G1/G2 dates。
- Visual：decision checklist with Approve / Condition / Defer / Re-scope。
- Discussion：今天可批准什麼、哪些需要condition / owner / due？
