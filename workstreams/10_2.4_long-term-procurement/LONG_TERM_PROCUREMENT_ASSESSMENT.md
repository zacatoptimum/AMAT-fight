# Long-term Procurement Assessment Memo v0.1

> `PRE-KICKOFF DRAFT`。所有 option / project / price / COD 資料皆為 `SYNTHETIC / DEMO DATA` 或 `RESEARCH REQUIRED`，不代表 AMAT 或市場現況。

## Executive decision

長期方案需用 risk-adjusted delivered value，而非 headline price 排序。先核准：可接受 contracting structures、volume / tenor range、COD tolerance、price / index boundaries、credit / security原則與不可接受的 risk allocation，再啟動 RFQ。

## Structure map

- retailer / bundled route：單一 commercial interface，但需驗證 underlying asset、pass-through、replacement與counterparty dependency；
- direct / project-linked PPA / CPPA hypothesis：較強 project linkage，需驗證 contracting / wheeling interface、project company / guarantee、COD與generation allocation；
- portfolio / aggregation：可能降低單一資產集中，需驗證 allocation transparency、substitution、certificate與settlement；
- phased / layered structure：分批 volume / start / tenor，可能保留選擇權，但治理與比較較複雜。

## Project maturity evidence

至少追蹤 site / land control、permits / approvals（按適用性）、interconnection / wheeling readiness、EPC / financing、equipment / schedule、commercial operation evidence、ownership / control、generation study、certificate path。具體法律與許可判斷交由 qualified counsel / technical advisor；Optimum做 commercial / evidence coordination。

## Commercial comparison

共同欄位：contract volume、expected profile、take / pay 或 as-generated、COD / delay、tenor、base price、escalation / index、settlement、curtailment、shortfall / replacement、wheeling / loss / service cost、T-REC ownership / timing、credit / guarantee、CP、change、termination與step-in / assignment。用 P50 / downside / delay scenarios 表達，不用一個單點遮蔽不確定性。

## Risk allocation questions

誰承擔 project delay、network delay、generation shortfall、curtailment、meter / data error、certificate late / invalid、law / tariff change、credit deterioration與force majeure？每項需有 event、owner、notice、measurement、remedy、cap / security與termination consequence。

## Preliminary judgement

`HYPOTHESIS`：shortlist 應優先保留 project evidence較完整、risk allocation可落地且與 client approval / implementation lead time相容的方案，即使 nominal price不是最低。實際結論需以 bidder data、financial / legal / technical DD驗證。

## Decision brief

核准 long-term volume / start / tenor range；hard constraints；price comparison metric；credit / guarantee boundary；COD / underdelivery tolerance；RFQ questions；需 counsel / specialist review 的項目；fallback / layered strategy。

## Handoff

2.5 response template 應逐欄取得上述資訊；2.6 scorecard須把 maturity與risk allocation獨立於 price；3.1鎖定 negotiation mandate；3.2把 unresolved allocation轉為 clause issue。
