# 2.4 中長期主力型採購方案評估 — Work Package

## Purpose
評估可承擔主要 volume 的長期 procurement structures、project dependencies 與 commercial / execution risk。
## Client question
哪些長期 route / projects 值得進入 structured RFQ / DD，AMAT 應承擔哪些風險來換取 volume、timing 或 price certainty？
## Intended decision
核准 long-term archetype、volume / tenor range、risk / credit boundary 與 RFQ market tests。
## Client audience
Procurement、Finance / Treasury、Legal、Sustainability、Facilities、regional / global approvers。
## Optimum owner / supporting role
Commercial Lead owner；Market / Project analyst；Finance / risk、Legal counsel、technical / facilities 支援；Project Lead review。
## Inputs
1.4 gap、1.5 scenario direction、2.1 landscape、2.2 written feedback、client credit / policy / approval boundary。
## Activities
structure map → project maturity / supply profile → commercial model → risk allocation → sensitivities → decision brief。
## Outputs
`LONG_TERM_PROCUREMENT_ASSESSMENT.md/.docx`、`Long_Term_Commercial_Comparison.xlsx`、`MODEL_README.md`。
## Dependencies
餵 2.5 pricing / response fields、2.6 DD / scorecard、3.1 mandate與3.2 contract checklist。
## Known
長期方案的價格不能脫離 volume / profile、COD、tenor、indexation、curtailment / shortfall、wheeling、certificate與credit條件比較。
## Hypotheses
project maturity / execution probability 可能比 headline price 更影響 risk-adjusted value。
## TBD with client
tenor limit、credit / guarantee、accounting / budget、price metric、technology / profile、COD tolerance、risk acceptance與signing authority。
## Key risks
COD slip、volume underdelivery、concentration、curtailment、unbalanced settlement、network / wheeling、certificate delay、credit / security、termination / change rigidity。
## MVP sequence
兩個 structure archetypes + one project demo → key sensitivities → client risk-boundary review → market evidence → RFQ-ready assumptions。
## Definition of Done
每個 option 有 maturity、COD、volume / profile、tenor、price / index、credit、risk allocation、wheeling、T-REC、sensitivity與open DD；decision brief能核准 RFQ scope。
