# Implementation_Tracker.xlsx — Model README

Sheets：`Governance Summary`、`Milestones`、`Delivery`、`Certificates`、`Reconciliation`、`Commercial Issues`、`Periodic Report`、`BAU Transition`。Delivery / certificate / invoice 用 stable keys 連結；公式計算 delivery variance、unmatched certificate MWh、invoice variance 與 open counts。Demo period 僅測試流程，正式 threshold、aging / SLA 邏輯與 data mapping 需依 signed contract / client systems 設定。
