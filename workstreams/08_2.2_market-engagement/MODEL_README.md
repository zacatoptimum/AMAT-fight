# Interaction_Tracker.xlsx — Model README

Sheets：`Contact Plan` 管 authority / purpose；`Interactions` 留下逐次記錄；`Comparable Responses` 將回答標準化；`Red Flags` 管 stop / escalation；`Feedback Memo` 彙整 decision-useful patterns。所有 seeded rows 為 `SYNTHETIC / DEMO DATA`。

先填 yellow inputs；one interaction per row，不覆蓋舊說法。口頭回答標 `Supplier oral statement`；只有 attached / logged evidence 才能提高 confidence。Feedback Memo 的計數只支援流程 QA，不代表市場統計。正式使用前以 G5 authorization、client contact protocol 與 NDA 要求替換 demo。
