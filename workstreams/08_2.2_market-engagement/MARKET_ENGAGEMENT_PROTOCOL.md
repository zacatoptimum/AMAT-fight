# Market Engagement Protocol v0.1

> `PRE-KICKOFF DRAFT`。實際 client identity、需求、contact list 與 disclosure authority 全為 `TBD WITH CLIENT`。本 protocol 不代表任何採購承諾。

## 1. Objective and boundary

接觸目的只在驗證 market hypotheses：供應類型、availability range、maturity、contracting route、timing、tenor、pricing structure、wheeling / meter、certificate treatment 與 next evidence。初步 sounding 不得被描述成競標、award 或 AMAT commitment。

## 2. Pre-contact brief

每次 contact 前填：decision question、target organisation / role、why selected、approved disclosure level、可說／不可說、五個 common questions、client / Optimum speaker、record owner、stop triggers、follow-up deadline。沒有 written G5 authority 就停在 public desktop research。

## 3. Disclosure script

可接受開場：

> Optimum is conducting a buyer-side market assessment. We are not requesting a binding offer at this stage. We would like to understand general capability and the evidence required for a later structured process. Any information shared will be recorded with its source and status; please identify confidential content.

若 client identity 未授權：

> The buyer identity, exact sites, volume and timing are not disclosed at this stage. Please respond using capability ranges and assumptions. This discussion does not create exclusivity or commitment.

不得暗示「client 已選中你」、「只剩你一家」、「數量已核准」或以另一家 offer 壓價。

## 4. Common supplier questionnaire

1. contracting entity、role、license / qualification evidence（如適用）；
2. available route / asset、control relationship 與 double-count prevention；
3. technology、location band、maturity、COD / start range 與 evidence；
4. volume / profile range、firmness、seasonality、curtailment / shortfall treatment；
5. tenor、minimum block、ramp / flex / exit options；
6. price structure / index / escalation / settlement components（初步可用結構，不索取未授權 quote）；
7. wheeling、meter、site / network prerequisites 與 lead time；
8. T-REC issuance / transfer / timing / ownership / replacement；
9. credit、guarantee、CP 與 parent / project-company interface；
10. confidentiality classification、next evidence、validity date、contact owner。

所有回答分成 `written supplier statement`、`oral statement`、`official evidence`、`Optimum inference`；沒有文件不能升格為 verified。

## 5. Email and meeting pattern

**Subject:** Non-binding Taiwan renewable electricity market sounding — capability discussion

Email body：說明 buyer-side role、non-binding、disclosure boundary、agenda、requested ranges / evidence、confidential marking、30–45 分鐘時間與 single point of contact。附件使用 approved questionnaire；不夾帶 client confidential files。

Meeting agenda：5 分鐘目的／邊界；20 分鐘 common questions；10 分鐘 evidence / gaps；5 分鐘 next steps。會後 24 小時內送 internal record；若需對外確認，只確認 factual record，不送他方比較。

## 6. Comparable fields and feedback memo

Market feedback memo 應只回答：哪些 hypothesis 被支持／否定；available range 與證據；共同 commercial patterns；material variations；unresolved red flags；對 2.3 / 2.4 / RFQ field 的 implication；建議 expand / stop / clarify。不得把單一 supplier statement 寫成 market fact。

## 7. Red flags and stop rules

- 要求未授權的 client identity / exact data 才願意繼續；
- 要求分享 competitor offer、未公開 pipeline 或 personal information；
- 施壓要求 exclusivity、commitment 或 bypass client process；
- asset ownership / control、license、COD、volume 或 certificate story 前後矛盾；
- 不願書面確認 material statement 或 confidentiality terms；
- Optimum / team member 有未揭露 conflict。

遇到時停止承諾、記錄原話與來源、通知 Project Lead；必要時由 client Legal / Procurement 決定是否續行。

## 8. Acceptable / unacceptable conduct

| Acceptable | Unacceptable |
|---|---|
| 對所有受訪者使用相同 core questions | 用關係熟悉度取代 evidence |
| 說明目前只是 non-binding assessment | 暗示 award、volume 或 deadline 已核准 |
| 將他家條件抽象成 client criterion | 揭露另一供應商名稱、價格或 confidential terms |
| 把不確定回答標成 supplier statement | 把口頭 claim 改寫成 verified fact |
| 中立說明 gaps 與 follow-up evidence | gossip、人格評斷、利用 client pipeline 當 social currency |

## 9. Review and handoff

每週 review interaction coverage、unanswered fields、red flags、stale validity 與 disclosure incidents。2.3 / 2.4 只讀取 comparable fields；2.5 RFQ 將 repeated ambiguities 轉成 mandatory response field；2.6 DD 追蹤未驗證 evidence，不重問無目的問題。
