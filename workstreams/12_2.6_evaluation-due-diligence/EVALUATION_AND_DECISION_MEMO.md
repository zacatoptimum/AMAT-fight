# Evaluation, Due Diligence & Shortlist Decision Memo v0.1

> `PRE-KICKOFF DRAFT`。任何 bidder、offer、score、price與recommendation為 `SYNTHETIC / DEMO DATA`；正式結果需由 client-approved evaluation body決定。

## Decision requested

對每個 offer 選：`SHORTLIST`、`SHORTLIST WITH CONDITIONS`、`RESERVE`、`DO NOT PROCEED`。同時核准 DD / clarification owners、negotiation boundary與fallback；不要只批准一個排名。

## Evaluation sequence

1. submission integrity / timeliness / conflict declaration；
2. mandatory field completeness與hard constraints；
3. normalize volume、profile、start、tenor、currency / unit、price components與validity；
4. evaluators先獨立score並附evidence comment；
5. calibration只調整共同rubric，不用權威壓掉dissent；
6. DD驗證 project / counterparty / certificate / execution / commercial claims；
7. sensitivity與condition mapping；
8. decision body記錄reason、conditions與risk acceptance。

## Scorecard design

建議分開：eligibility / hard screen；volume / timing；commercial / normalized cost；flexibility；project maturity；execution / wheeling；certificate / claim；counterparty / credit；contract / risk allocation；evidence confidence。權重與scale需G6/G7核准，且evidence confidence不可藏在總分中。

## Due diligence checklist

- entity / authority / ownership / conflict；
- project control、maturity、COD schedule、financing / construction evidence（適用時）；
- generation / volume / profile、allocation與duplicate / overcommitment；
- wheeling / interconnection / meter / site dependencies；
- T-REC issuance / transfer / ownership / timing / replacement / no double claim；
- pricing / settlement model reconciliation、tax / fee / pass-through；
- credit、guarantee、security、parent / project-company interface；
- delay、shortfall、curtailment、FM、change、default、termination positions；
- implementation resources、data / reporting、BAU support；
- legal / technical / financial specialist items與formal advice boundary。

## Risk assessment

每項risk記 event、likelihood / impact（定義後）、evidence、current allocation、mitigation / condition、residual risk、risk acceptor與decision date。Red flag不等於automatic rejection，但未經授權不可自行接受。

## Preliminary judgement

`HYPOTHESIS`：較好的 shortlist 不是單一最高分，而是至少保留一個 primary option與一個可執行 fallback，並把最關鍵DD gap轉成 condition-to-negotiate。實際 shortlist size需client決定。

## Decision output

一頁呈現：offer / route、hard-screen、normalized commercial range、score range、top 3 strengths、top 3 risks、open DD、condition、recommendation、next gate。附錄保留rubric、source links、normalization與dissent；不把細節塞入executive deck。

## Handoff to 3.1

Shortlist package需包括 final demand / volume / timing assumptions、offer validity、commercial deviations、must-have / tradeable terms、risk acceptance required、fallback、negotiation participants與authority gaps。
