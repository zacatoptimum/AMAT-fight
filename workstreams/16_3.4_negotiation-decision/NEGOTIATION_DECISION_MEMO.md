# Negotiation & Internal Decision Memo v0.1

> `PRE-DECISION STRUCTURE DRAFT`。所有supplier、terms、numbers、options與recommendation皆為 `SYNTHETIC / DEMO DATA` 或 `TBD WITH CLIENT`。

## Decision requested

選擇：`ACCEPT SUBJECT TO DOCUMENTS`、`COUNTER WITH MANDATE`、`CONTINUE CLARIFICATION`、`SWITCH / ACTIVATE FALLBACK`、`PAUSE` 或 `STOP`；同時核准residual risks、conditions、owner / date與external communication。

## What changed

從上次G8 / round-1 baseline只呈現material deltas：volume / timing、price / index / settlement、COD / shortfall、wheeling / certificate、credit / security、default / termination、implementation / data。每項引用term / issue ID與controlled document version。

## Decision scenarios

1. **Preferred package**：best current integrated terms + unresolved conditions；
2. **Counter package**：specified trade / authority / expiry；
3. **Fallback**：reserve bidder / structure / bridge / reduced volume；
4. **No-deal / delay**：gap、budget、deadline、resource與relationship effect。

比較 normalized cost / exposure、coverage / timing、execution confidence、certificate / claim、credit、contract residual risk、internal readiness與option value。若不能量化，用range + reason + confidence。

## Risk acceptance

每項residual risk列 event、downside、likelihood / impact definition、current allocation、mitigation、counsel / specialist view、risk acceptor、decision。沉默不等於接受；條件式接受需具體condition與deadline。

## Preliminary judgement

`HYPOTHESIS`：只有當remaining P0 / P1 issues已有accepted allocation或可在signing前以明確condition關閉，才適合進3.5；否則應維持counter / fallback，不用進度壓力取代decision。

## Decision record

記錄chosen option、reason、rejected alternatives、assumptions、dissent、conditions、authorized message、next document owner、validity / expiry與next gate。Supporting methodology與完整redlines留在tracker / counsel workspace，不塞進executive deck。
