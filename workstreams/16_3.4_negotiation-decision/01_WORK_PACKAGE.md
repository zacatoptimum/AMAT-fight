# 3.4 後續談判與內部決策 — Work Package

## Purpose
將remaining issues、revised economics、risk acceptance與alternatives轉成一次可決定的內部decision pack與下一輪mandate。
## Client question
依目前條件要accept、counter、continue、switch、pause還是stop？哪些risk需要誰接受？
## Intended decision
G9：preferred commercial package、remaining red lines、risk acceptance、next-round authority與fallback。
## Client audience
Executive / decision body、Procurement、Finance、Legal、Sustainability、Facilities、regional / global approvers。
## Optimum owner / supporting role
Project Lead owner；Commercial Lead model / recommendation；Legal / specialists advice；client decision owner決定。
## Inputs
3.3 outcomes、latest offer / redline、3.2 issue tracker、revised economics、alternatives / validity。
## Activities
reconcile changes → impact model → open issue / risk register → option comparison → recommendation → decision → mandate refresh。
## Outputs
`NEGOTIATION_DECISION_MEMO.md/.docx`、`Position_Tracker.xlsx`、`MODEL_README.md`、`DECISION_PACK_CONTENT.md`與精煉 decision deck。
## Dependencies
decision後進3.5；若未ready則指定下一輪、fallback或stop。
## Known
已同意in principle不等於可簽；terms需以latest controlled version與specialist advice核對。
## Hypotheses
把remaining issues量化為commercial impact + residual risk + approval requirement，可避免只討論redline字句。
## TBD with client
decision quorum、risk acceptor、budget / NPV metric、best alternative、offer validity、final mandate與communication route。
## Key risks
sunk-cost bias、latest version錯誤、只看price、risk acceptance未記錄、alternative失效、decision delay錯過validity。
## MVP sequence
one-page delta → top open issues → 3 scenarios → Project Lead challenge → decision body → tracker / mandate update。
## Definition of Done
每個option有current terms、delta、cost / risk / implementation effect、open issue、counsel status、recommendation / condition、owner / expiry；decision完整記錄。
