# Kickoff Deck — Content Source

## Storyline

Kickoff 不用大量介紹市場，而是先把「共同要做出的決策、誰參與、如何在未知中快速校準」談清楚。8 slides 依序從 outcome、method、journey、governance、work rhythm、inputs、risks、immediate decisions 推進。

## Slide 1 — A shared decision system will let AMAT move from requirements to execution without late-stage rework

- Key message：本案不是一串孤立 deliverables，而是一條從 requirement definition 到 contracting / execution 的 decision path。
- Intended content：title；subtitle `AMAT Taiwan Renewable Electricity Advisory | Kickoff discussion draft`；PRE-KICKOFF / TBD statement。
- Visual concept：單一路徑由 Define → Evaluate → Negotiate → Execute；不要 stock photo。
- Client question：今天需要確認哪些 outcomes 與 governance，才值得正式啟動？

## Slide 2 — We will define success through the decisions AMAT must make, not through document volume

- Key message：每個 workstream 都需有 intended decision、decision owner 與使用方式。
- Intended content：四個 outcome blocks：requirements / portfolio、market / shortlist、commercial / contract、go-live / BAU；右側列 success evidence。
- Visual concept：四段 decision chain；支援文件在下方，不是主體。
- Discussion：AMAT 最重要的 3–5 個 decisions 是什麼？

## Slide 3 — The delivery journey uses ten gates to prevent analysis from outrunning authority or evidence

- Key message：G0–G9 讓範圍、資料、market disclosure、shortlist、mandate、signing、go-live 逐步獲准。
- Intended content：G0 Kickoff、G1 Requirements、G2 Portfolio、G3 Market Launch、G4 RFQ、G5 Shortlist、G6 Mandate、G7 Select / Sign、G8 Go-live、G9 Performance。
- Visual concept：horizontal gate map grouped 1.x / 2.x / 3.x。
- Client question：哪些 gate 需要 Taiwan、regional 或 global approval？

## Slide 4 — Cross-functional participation changes by decision; a single standing audience is not enough

- Key message：Sustainability、Procurement、Facilities、Finance、Legal、regional / global stakeholders 應按決策參與。
- Intended content：RACI hypothesis in compact matrix；all roles marked HYPOTHESIS。
- Visual concept：editable table，rows為 major decisions，columns為 stakeholder groups。
- Client question：誰 accountable、誰必須 consulted、誰只需 informed？

## Slide 5 — Define → MVP → Review → Correct → Expand is the default working rhythm

- Key message：高不確定性工作先用 small artifact 驗證方向，避免數週後才第一次 review。
- Intended content：five-step loop；biweekly working review / monthly or gate steering as starting hypothesis；review SLA。
- Visual concept：closed loop + two review forums。
- Client question：client reviewers 的正常 turnaround 與 urgent escalation route 是什麼？

## Slide 6 — The first four weeks should lock governance, data ownership, market understanding and the gap-analysis method

- Key message：前四週先建立可支撐後續 decision 的共同基礎。
- Intended content：Week 0 kickoff、Week 1 data / interviews、Week 2 workshop、Week 3 gap MVP、Week 4 portfolio preview；actual timing TBD。
- Visual concept：compact timeline with client inputs above and Optimum MVP below。
- Client question：哪些 fixed dates、data constraints 或 stakeholder calendars 會改變 sequencing？

## Slide 7 — Early visibility of unknowns is a control, not a weakness

- Key message：最重要的未知是 success definition、boundary、authority、data owners、market disclosure 與 legal / procurement process。
- Intended content：KNOWN / HYPOTHESIS / TBD / RESEARCH REQUIRED legend；top risks and mitigating control。
- Visual concept：risk-to-control mapping，最多 6 rows。
- Client question：今天有哪些 assumption 必須立即更正？

## Slide 8 — Today’s decisions launch 1.2 data collection and 1.3 workshop design

- Key message：kickoff 的完成標準是明確 decisions / owners / dates，而非「介紹完畢」。
- Intended content：decision checklist：outcomes、scope boundary、sponsor / owners、cadence、review SLA、repository / security、data owner、workshop participants、next gate dates。
- Visual concept：decision checklist with owner / due columns。
- Client question：哪些項目可今天 Approve、Approve with conditions、Defer 或 Re-scope？

## Speaker / discussion guidance

- 不陳述任何未驗證 AMAT volume、site、target、budget、policy、stakeholder name 或 supplier preference。
- 每頁結尾先問 decision / validation question，再討論 detail。
- 會後 48 小時內將答案轉成 charter、decision log、client question log、schedule 與 1.2 / 1.3 launch actions。
