## 2. Objectives and non-objectives

### Objectives

- 先確認 client decisions 與使用者，再決定分析深度與格式。
- 建立 baseline / residual gap 與採購組合的可追溯口徑。
- 用一致資訊欄位掃描、接觸、比較與篩選市場選項。
- 把 commercial review、legal advice、negotiation authority 與 internal approval 清楚區分。
- 將簽約成果交接成可長期追蹤的 execution governance。

### Non-objectives unless explicitly contracted

- 提供法律、稅務、會計、工程或投資保證。
- 代表 AMAT 作未授權承諾、簽約、揭露 client identity / exact volume。
- 為特定供應商背書，或保證市場價格 / availability / project COD。
- 以未驗證 AMAT-specific facts 建立 recommendation。

## 5. Ways of working

### Before any material task

Task brief 必須回答 Objective、Expected Output、Intended Use、Approach、Inputs、Unknowns、Questions to Confirm、First MVP、Review Point、Definition of Done。沒有這十項，不進入長時間 production。

### Review rhythm

| Forum | Default purpose | Proposed cadence | Output |
|---|---|---|---|
| Analyst / Optimum review | 方法、evidence、preliminary judgement | working days as needed | corrected MVP / review note |
| Client working session | 解開資料 / 假設 / design 問題 | biweekly HYPOTHESIS | decisions / actions / client questions |
| Steering / sponsor review | gate decision、risk acceptance、scope change | monthly or at gate HYPOTHESIS | signed-off decision record |
| Market interaction | 取得可比較的供應資訊，不做未授權承諾 | controlled by 2.2 protocol | interaction record / red flags |

### Review SLA hypothesis

- Pre-read：重要 decision material 原則上會前 2 個工作天。
- Working review：指定 reviewer 原則上 2 個工作天內回覆或說明新日期。
- Decision：若未定案，必須記錄 pending owner、missing evidence、latest-needed date，不把沉默視為同意。
- Urgent issues：confidentiality、false commitment、material scope / price / legal exposure 立即升級。

## 6. Decision process

1. Analyst 明確陳述 decision requested，而不只報告活動。
2. 將 KNOWN、HYPOTHESIS、TBD、SYNTHETIC、RESEARCH REQUIRED 分開。
3. 列 feasible options、recommendation、trade-offs、required evidence、reversibility。
4. Decision owner 可選 Approve / Approve with conditions / Request revision / Defer / Stop。
5. 48 小時內將 rationale、conditions、actions、owner、date、affected artifacts 寫入 Decision log。
6. 對 scope、cost、timeline 或 assumption baseline 的重大改變，進 Change log。

## 7. Issue and escalation process

| Trigger | Immediate action | Escalation owner | Target response |
|---|---|---|---|
| Confidentiality / accidental disclosure | Stop / Report / Contain / Document | Project Lead + authorized security contact | Immediate |
| Unclear authority / market commitment | Pause external response | Project Lead + Procurement / Legal | Before reply |

| Scope / timeline impact | Log change with options and consequences | Project Lead + client sponsor | Next steering or urgent review |
| Potential conflict | Pause affected contact; document; consider recusal / barrier | Project Lead | Before engagement |
