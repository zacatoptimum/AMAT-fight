# Short-term Procurement Assessment Memo v0.1

> `PRE-KICKOFF DRAFT`。所有 volume、price、availability 與 option rows 皆為 `SYNTHETIC / DEMO DATA`；AMAT eligibility / claim policy 為 `TBD WITH CLIENT`。

## Executive decision

短期方案只應處理明確 residual timing gap，並保留中長期主力方案的選擇權。決策不是「最便宜是哪個」，而是：在 approved eligibility、delivery confidence 與 certificate control 下，以多大 volume、何種 tenure 取得可接受的 bridge。

## Assessment logic

先做 hard screens：claim / eligibility、delivery period、certificate ownership / transfer、no double count、minimum volume / site fit、information / conflict red flags。通過後比較 availability confidence、all-in cost structure、tenor、start timing、volume flex、technology / vintage、settlement、replacement、execution resources 與 market dependency。

## Option archetypes

| Archetype | Potential role | Strength | Main issue to verify |
|---|---|---|---|
| Short bundled supply | electricity + certificate bridge | 可能簡化 interface | 真實 availability、wheeling / meter、價格組成 |
| Unbundled certificate | residual claim bridge（若 policy 允許） | speed / granularity | eligibility、vintage、ownership、replacement、double claim |
| Short portfolio / retailer product | 分散多資產 / 較彈性 | aggregation | underlying asset evidence、allocation、reconciliation、counterparty dependency |

這些是分析 archetype，不代表台灣市場當期一定存在，也不是 AMAT recommendation。

## Cost and risk view

模型至少分開：energy / premium、certificate、wheeling / service、fees、tax treatment、settlement / index、one-off implementation、replacement / shortfall exposure。無 quote 時用 range + confidence，不用單點假精準。比較 annual / cumulative cost、NTD/MWh、coverage、uncovered gap、concentration 與 flexibility。

## Preliminary judgement

`HYPOTHESIS`：先保留一個 small / flexible bridge option，可降低長期 project COD 或 approval slip 的衝擊；但若 eligibility、certificate control 或 supplier evidence 不足，應選 `reserve / research more`，不可只因短期可買就 proceed。

## Decision brief

會議需決定：bridge need / max volume、eligible archetype、maximum tenor、required evidence、budget metric、go / pilot / reserve / reject、與 2.4 的 replacement / expiry trigger。任何 approved-with-condition 都要有 owner 與 date。

## Handoff

Selected option fields直接成為 2.5 mandatory response columns；2.6 hard screen 必須包括 eligibility / certificate / delivery；3.1 記錄 final volume、validity、price structure 與 fallback。
