# 2.3 短期補充型採購方案評估 — Work Package

## Purpose
評估能否用較短 lead time / tenor 的工具補足 residual timing gap，同時不犧牲 claim eligibility、證書控制與未來 portfolio flexibility。
## Client question
在中長期主力方案到位前，什麼 bridge 可降低 gap，代價與風險為何？
## Intended decision
選擇 proceed / pilot / reserve / reject 的短期工具與 volume range。
## Client audience
Sustainability、Procurement、Finance、Legal、Facilities、decision body。
## Optimum owner / supporting role
Commercial Lead owner；Analyst model；policy / certificate、Finance、Legal 支援；Project Lead recommendation review。
## Inputs
1.4 residual gap、1.5 constraints、2.2 availability feedback、eligibility policy、budget / approval boundary。
## Activities
定義 bridge need → hard-screen eligibility / delivery → compare availability / cost / tenor / certificate / flexibility → sensitivity → decision brief。
## Outputs
`SHORT_TERM_PROCUREMENT_ASSESSMENT.md/.docx`、`Short_Term_Option_Comparison.xlsx`、`MODEL_README.md`。
## Dependencies
承接 1.4 / 1.5 / 2.2；結果與 2.4 core strategy共同進入 2.5 / 2.6。
## Known
短期工具必須與 residual gap 年份、claim / certificate 與 existing procurement 重複檢查。
## Hypotheses
短期工具的主要價值可能是 speed / flexibility，而非最低 nominal price；實際適用性待 market evidence。
## TBD with client
eligible instruments、maximum tenure、budget metric、volume tolerance、vintage / technology preference、internal approval、risk appetite。
## Key risks
把 bridge 變成永久依賴；certificate timing / ownership 不清；double claim；低估 transaction / reconciliation cost；availability 口頭未驗證。
## MVP sequence
一年 residual gap + 3 個 synthetic option → client review criteria / eligibility → 補 evidence → multi-year / sensitivity → decision。
## Definition of Done
每個 option 有 volume、cost structure、timing、tenor、certificate、flexibility、delivery / claim risk與 evidence；recommendation 明確且與 2.4 不重複計量。
