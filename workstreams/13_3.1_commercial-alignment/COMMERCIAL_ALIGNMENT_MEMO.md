# Commercial Alignment Memo v0.1

> `PRE-NEGOTIATION STRUCTURE DRAFT`。Final volume、timeline、budget、shortlisted suppliers、offers與authority均為 `TBD WITH CLIENT`。Demo positions不可對外使用。

## Decision requested

G8 核准 negotiation mandate：final requirement range、priority / walk-away issues、trade authority、participants、approval route、supplier sequence與record protocol。若任何 material boundary 未核准，supplier discussion只能clarify，不能承諾。

## Final requirement assumptions

對齊並版本化：reporting / site boundary、residual gap、existing procurement、volume / profile、start / COD tolerance、tenor、technology / claim eligibility、certificate timing、wheeling / meter、budget metric、currency / tax、credit / guarantee、implementation lead time。每項記 source / date / status；禁止默認沿用過期 scenario。

## Term hierarchy

| Position | Meaning | Meeting rule |
|---|---|---|
| Must-have | 缺少即不符合approved need / policy / risk boundary | 不得交換；若 challenged 則 pause / escalate |
| Target | 支持 value / execution 的偏好結果 | 可用 package trade 取得 |
| Tradeable | 有明確對價與authority才可讓步 | 記錄 give / get / value / expiry |
| Unacceptable | 超出 risk / budget / policy / authority | 不承諾；提出 alternative 或退出 |

分級本身須由client approver核准；Optimum提出commercial judgement，不替client接受風險。

## Priority commercial issues

volume / firmness / profile；COD / longstop / delay remedy；tenor / ramp / flex / renewal / exit；price components / index / settlement；wheeling / loss / site cooperation；T-REC ownership / issuance / replacement；curtailment / shortfall；credit / guarantee；CP；change / force majeure；default / termination；implementation / data / BAU。

## Negotiation objectives

每項 objective 用五欄表達：desired outcome、business rationale、supplier interest hypothesis、fallback / alternative、authorized trade。不能用「best terms」等模糊語句；要能在會後判斷是否前進。

## Alignment meeting agenda

1. confirm decision and facts that changed；2. approve assumptions / validity；3. review top issues and red lines；4. agree package trades；5. assign speaking / note / escalation roles；6. approve next supplier interaction；7. record dissent / conditions。

## Preliminary judgement

`HYPOTHESIS`：先鎖定少量高價值 issues與跨term trade packages，可避免逐條討價導致整體 risk allocation惡化；但 actual mandate完全取決於 client approvals與 counsel input。

## Handoff

3.2 將top issues映射至 clauses / legal questions；3.3 使用同一 term IDs與authority；3.4只比較經驗證的remaining differences；3.5把agreed terms轉成final documents / CP / implementation responsibilities。
