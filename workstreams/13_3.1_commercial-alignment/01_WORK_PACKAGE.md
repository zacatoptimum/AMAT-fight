# 3.1 最終需求與商業條件對齊 — Work Package

## Purpose
把 G7 shortlist、最終需求、offer validity、must-have / tradeable terms與decision authority鎖成可執行的談判 mandate。
## Client question
我們準備談什麼、希望換到什麼、哪些不能讓、誰可以決定？
## Intended decision
G8：核准 negotiation objectives、volume / timeline / structure assumptions、priority issues、walk-away / escalation與authorized team。
## Client audience
Decision body、Procurement、Finance、Legal、Sustainability、Facilities、regional / global approvers。
## Optimum owner / supporting role
Commercial Lead owner；Project Lead QC；client Procurement lead；Finance / Sustainability define boundaries；Legal counsel owns legal advice。
## Inputs
2.6 shortlist / DD / risks、offers / validity、1.4 / 1.5 updated demand、client approvals / policies、3.2 draft issue taxonomy。
## Activities
revalidate need → reconcile term positions → classify must / target / tradeable / unacceptable → set authority → alignment meeting → issue negotiation brief。
## Outputs
`COMMERCIAL_ALIGNMENT_MEMO.md/.docx`、`Commercial_Term_Tracker.xlsx`、`MODEL_README.md`與alignment meeting page。
## Dependencies
輸出是 3.2 review scope與3.3 mandate；任何未對齊事項不得在supplier meeting即席承諾。
## Known
Shortlist不等於award；offer validity / assumptions可能已變；legal advice由qualified counsel提供。
## Hypotheses
逐term定義 objective / rationale / fallback / authority，比單一bottom-line更能控制cross-functional negotiation。
## TBD with client
final volume / timing、budget / accounting、authority、walk-away、risk acceptor、legal counsel、approvals / quorum、supplier sequencing。
## Key risks
團隊內部立場矛盾；authority不清；已過期offer；volume / price / risk不同步；未記錄verbal commitment；legal / commercial混淆。
## MVP sequence
一頁 assumptions + top 10 terms → client alignment → term tracker → mock negotiation → G8 approval。
## Definition of Done
每項term有current / target / fallback / unacceptable、rationale、authority、evidence、owner與open question；meeting participants知道何時pause / escalate。
