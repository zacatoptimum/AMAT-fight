# 1.6 跨部門對齊與 RE100 路徑圖 — Work Package v0.1

> PRE-KICKOFF DRAFT。Roadmap日期、owners、approval bodies與AMAT portfolio direction均為 `TBD WITH CLIENT`；示意 gates 是 delivery architecture，不是已核准 client schedule。

## Purpose

把1.4 gap與1.5 portfolio direction轉成跨部門可執行的 short / medium / long-term roadmap，明確定義 decision gates、owners、dependencies、approval points與進入2.x的授權。

## Client question

AMAT要在何時由哪些 stakeholders做哪些 decisions、完成哪些 evidence / approvals，才能把 renewable procurement strategy安全地帶入市場並落地？

## Intended decision

G5：核准 roadmap、governance、2.x market activity、disclosure boundary、resources與第一批 market questions。

## Client audience

Sponsor / steering、Sustainability、Procurement、Facilities、Finance、Legal、regional / global owners；named roles與authority `TBD WITH CLIENT`。

## Optimum owner / supporting role

Owner：project lead；support：analysis lead、market SME、PMO；client owners各自負責 data / policy / commercial / legal / implementation decisions。

## Inputs

G3 gap / range、G4 portfolio direction / conditions、decision / assumption / risk / action logs、stakeholder map、client procurement / legal / approval processes。

## Activities

1. 對齊 objective、decision rights與 roadmap horizon。
2. 把 near / medium / long-term actions連到 named gates與exit evidence。
3. 指派 accountable / responsible / consulted roles。
4. 標示 critical path、external / internal dependencies與escalation。
5. 核准2.x scope、market conduct / confidentiality boundary與MVP sequence。

## Outputs

`ALIGNMENT_ROADMAP.md/.docx`、`ROADMAP_DECK_CONTENT.md`、`Roadmap_Deck.pptx`。

## Dependencies

Upstream：1.1–1.5。Downstream：2.1 scan、2.2 engagement、2.3 / 2.4 assessments、2.5 RFQ、2.6 shortlist。

## Known

2.x不得在 disclosure boundary與decision authority未核准時啟動 named outreach。Gates需以 evidence / decision定義，不以會議日期代替。

## Hypotheses

Near term優先補 evidence / gap與低承諾市場測試；medium term執行shortlist / RFQ；long term進入commercial alignment / contracting / implementation。實際次序可能因AMAT deadline或market opportunity調整。

## TBD with client

Sponsor、decision body、approval threshold、budget / resources、target / procurement dates、named owners、internal procurement / legal lead time、external counsel、disclosure authorization、2.x launch date。

## Key risks

Roadmap只有activity沒有decision；owner是部門不是人；market activity先於authorization；long-lead legal / data / wheeling work太晚開始；short-term與long-term work互相脫節。

## MVP sequence

One-page gates → owner / evidence review → first 90-day action plan → dependency correction → expanded roadmap與2.x launch brief。

## Definition of Done

- short / medium / long-term actions、owners、dependencies、approval points清楚。
- 每個gate有decision、owner、exit evidence、latest-needed date與fallback。
- 2.x launch scope / disclosure boundary / market questions已核准或明確標condition。
- roadmap deck可支持client alignment，不重複methodology細節。
- outputs直接餵入2.1 / 2.2且保留G3 / G4 conditions。
